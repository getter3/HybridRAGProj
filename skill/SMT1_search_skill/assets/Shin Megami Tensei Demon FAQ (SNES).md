Introduction:

I've been looking around for a while and I have never been able to find a 
detailed list of all the demons that can be caught in Shin Megami Tensei. So I
though I might as well make one. As I find new demons, I will add them to the
database. Each demon profile will contain the demon's class, level, HP, MP, 
CP, alignment, abilities, and stats. I plan in future to include a fusion 
chart for the Jakyou.
